# Architecture assets

- [`azure-vmware-migration-factory.svg`](azure-vmware-migration-factory.svg) — high-resolution architecture diagram with embedded Azure service icons for Azure Migrate, Recovery Services Vault, Virtual Networks, Key Vault and Azure Monitor.
- [`azure-vmware-migration-factory.drawio`](azure-vmware-migration-factory.drawio) — editable diagrams.net source with editable architecture blocks, labels and connectors.

The diagram separates the source VMware estate, discovery/assessment, Azure landing zone, migration execution, validation and operations. It is a conceptual target design; it does not mean the pictured services have been deployed or connected.

For additional official product icons, use the [Microsoft Azure Architecture Icons](https://learn.microsoft.com/en-us/azure/architecture/icons/) collection and follow Microsoft's terms and guidance.
